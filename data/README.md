# Dataset notes

`customers.csv` is a numeric-only derivative of the user-supplied `Ecommerce Customers` CSV. Email, Address and Avatar were removed; the remaining values and row order are preserved. No external dataset was substituted.

Four numeric predictors and one target (`Yearly Amount Spent`). The source does not document currency, time units, data collection, population, or whether records are synthetic. Do not invent those details.
